===================================================================
                  TILE WORLD - MS TILESETS GUIDE
===================================================================

Place custom Microsoft (MS) ruleset tileset graphics in this directory.

Supported File Types:
- .bmp : Bitmap graphics files containing 32x32, 48x48, or 96x96 tile grids.

Instructions:
1. Copy your custom .bmp tileset file into this 'mstiles' folder.
2. Select your custom tileset from the Tileset dropdown menu when playing MS ruleset.
===================================================================
