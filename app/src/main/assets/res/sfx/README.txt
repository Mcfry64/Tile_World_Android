===================================================================
                  TILE WORLD - SOUND EFFECTS (SFX) GUIDE
===================================================================

Create custom Sound Effect (SFX) themes in this directory.

Instructions:
1. Create a subfolder inside 'sfx' with your theme name (e.g., sfx/MySoundTheme/).
2. Place your sound effect audio files (.wav) inside that folder.
3. Place an 'rc' sound mapping configuration file inside the theme folder.
4. Select your custom SFX theme from the SFX dropdown menu in Tile World.
===================================================================
