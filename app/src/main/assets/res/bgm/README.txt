===================================================================
                  TILE WORLD - BACKGROUND MUSIC (BGM) GUIDE
===================================================================

Create custom Background Music (BGM) themes in this directory.

Instructions:
1. Create a subfolder inside 'bgm' with your theme name (e.g., bgm/MyMusicTheme/).
2. Place your audio files in OGG Vorbis (.ogg) format inside that folder.
3. Select your custom BGM theme from the BGM dropdown menu in Tile World.

Note:
- For the official Microsoft "MS" theme, see the guide in bgm/MS/README.txt.
===================================================================
