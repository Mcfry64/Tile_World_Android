===================================================================
                  TILE WORLD - LYNX TILESETS GUIDE
===================================================================

Place custom Atari Lynx ruleset tileset graphics in this directory.

Supported File Types:
- .bmp : Bitmap graphics files containing Lynx tile grids.

Instructions:
1. Copy your custom .bmp tileset file into this 'lynxtiles' folder.
2. Select your custom tileset from the Tileset dropdown menu when playing Lynx ruleset.
