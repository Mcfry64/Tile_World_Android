===================================================================
                  TILE WORLD - DATA FOLDER GUIDE
===================================================================

Place custom level set files (.dat or .ccx) in this directory.

Supported File Types:
- .dat : Chip's Challenge binary level set files (e.g., CHIPS.dat, CCLP1.dat)
- .ccx : Extended Tile World level set files

Instructions:
1. Copy your .dat or .ccx level files into this folder.
2. If the level set uses a .dac file, place the corresponding .dac
   file in the 'sets' folder.
3. Restart Tile World or re-open the Level Set dropdown menu to play.
===================================================================
