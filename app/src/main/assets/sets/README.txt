===================================================================
                  TILE WORLD - SETS FOLDER GUIDE
===================================================================

Place custom level set configuration files (.dac) in this directory.

Supported File Types:
- .dac : Tile World set definition files linking level names, rulesets,
         and companion .dat / .ccx files.

Instructions:
1. Place your .dac configuration file into this 'sets' folder.
2. Ensure the referenced .dat / .ccx level files exist in the 'data' folder.
3. Re-open Tile World to see the new Level Set appear in the dropdown menu.
===================================================================
